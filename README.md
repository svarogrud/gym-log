# Gym Log

Журнал тренувань для телефона: три дні програми, підходи й ваги, таймер відпочинку,
власні вправи, історія з Google Sheets і резервна копія туди ж.
Працює як PWA: встановлюється на головний екран Android та iPhone і працює офлайн.

Дані зберігаються на телефоні. Таблиця — джерело історії й резервна копія:
після завершення тренування апка додає стовпець, виконані вправи зафарбовує кольором дня
(ноги — помаранчевий, плечі й спина — синій, груди й руки — фіолетовий), пропущені лишає білими.
Якщо інтернету немає, запис дочекається мережі.

## Налаштування (один раз)

### 1. Скрипт у таблиці

1. Відкрийте таблицю Gym → **Розширення → Apps Script**.
2. Видаліть вміст `Code.gs` і вставте файл [`apps-script/Code.gs`](apps-script/Code.gs).
3. У рядку `const TOKEN = '…'` впишіть свій довгий випадковий ключ (наприклад, 30+ букв і цифр). Збережіть.
4. **Deploy → New deployment** → тип **Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
5. **Deploy**, дозвольте доступ до таблиці (Google попередить про неперевірений застосунок:
   *Advanced → Go to … (unsafe)*, бо це ваш власний скрипт).
6. Скопіюйте **Web app URL** (закінчується на `/exec`).

Адреса й ключ разом дають доступ до таблиці, тому нікому їх не пересилайте.
У репозиторії їх немає: вони вводяться в апці й зберігаються тільки на телефоні.

Після змін у `Code.gs`: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
(адреса лишається та сама).

### 2. GitHub Pages

**Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `(root)` → Save.**
За хвилину апка буде на `https://svarogrud.github.io/gym-log/`.

### 3. Телефон

- **Android (Chrome):** відкрийте адресу → меню ⋮ → **Install app / Встановити застосунок**.
- **iPhone (Safari):** відкрийте адресу → **Поділитися** → **На екран «Додому»**.

Відкрийте апку → **⚙** → вставте адресу скрипта і ключ → **Зберегти й перевірити** →
внизу журналу **Імпортувати історію з таблиці**.

## Файли

| Файл | Що це |
|---|---|
| `index.html`, `app.css`, `app.js` | сама апка |
| `manifest.webmanifest`, `sw.js`, `icons/` | встановлення й офлайн-режим |
| `apps-script/Code.gs` | міст між апкою і таблицею |

Оновлення: після змін у репозиторії апка підтягує нову версію з другого запуску
(перший запуск оновлює кеш у фоні). Щоб примусово оновити, змініть `CACHE` у `sw.js`.
